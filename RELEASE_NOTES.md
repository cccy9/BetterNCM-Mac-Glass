# BetterNCM Mac Glass 1.8.88

## 中文

基于 BetterNCM 的 Windows 网易云音乐玻璃主题整合安装器，感谢 BetterNCM 原作者及贡献者。

- 内置 Mac Glass Theme 和 x86/x64 原生窗口插件，安装后随网易云启动。
- 提供主窗口及播放页透明度、底栏磨砂、歌词纯色/渐变及播放页背景设置。
- 统一欢迎页名称和整合版版本；“开始使用”直接进入 Mac Glass 设置页。
- 修复安装器构建依赖及旧版本索引地址，下载失败时显示错误。

下载 **BetterNCM-Mac-Glass-Installer.exe**，接受管理员权限提示后，首次使用选择“安装”，已有 BetterNCM 则选择“重装/更新”。安装会关闭并重新启动网易云。ZIP 包另附许可证、说明和校验文件。

安装需要联网获取匹配的 BetterNCM 核心及所需运行库。整合版版本号为 1.8.88，核心保留自己的版本号。Windows 整窗透明会同时淡化文字和封面；网页磨砂不能调节桌面背景模糊半径。

## English

A glass-theme installer for NetEase Cloud Music on Windows, built on BetterNCM. Thanks to the original BetterNCM authors and contributors.

- Bundles Mac Glass Theme and native x86/x64 window plugins that load with the client.
- Adds main/playback window transparency, player-bar web blur, lyric colors/gradients and playback background settings.
- Updates the welcome page and distribution version; the Start button opens Mac Glass settings directly.
- Fixes build dependencies and the outdated version-index URL, with download error reporting.

Download **BetterNCM-Mac-Glass-Installer.exe**, accept the administrator prompt, then choose Install or Reinstall/Update if BetterNCM is already installed. Installation closes and restarts NetEase Cloud Music. The ZIP also includes the license, README and checksum file.

Internet access is required for the matching BetterNCM core and required runtimes. Distribution version 1.8.88 is independent of the core version. Whole-window alpha also fades text and cover art; web blur does not control the desktop background blur radius.
